## 阅读顺序

1. `00`：先确定公理、双层规则与时标映射。
2. `01`–`10`：按依赖顺序阅读各子系统设计。
3. `11`：总装与最小可构建集。
4. 每册 `§5` 与 `§10`：验证计划、适用边界与已知限制。

## 各册通用结构

| 章节 | 内容 |
|---|---|
| 文档控制块 | 模块、文档类型、版本、依赖、语言 |
| `§0` | 设计方案比选（方案 A/B/C）、组合与基线配置、结构说明 |
| `§1` | 设计目标 |
| `§2` | 相关研究现状与不同实现方式 |
| `§3` | 设计正文（结构、机制、公式、接口） |
| `§4` | 与其他部分的关系（接口契约） |
| `§5` | 验证计划与待测定参数 |
| `§10` | 适用边界与已知限制 |

`00` 与 `11` 因定位不同，章节顺序略有调整：前者含公理与决策记录，后者含全项目验证项汇总与实施顺序。

## 依据类别标注

| 标记 | 含义 |
|---|---|
| `[引用:…]` | 有文献或数据支撑，指向文献库中的具体文件 |
| `[设计决策]` | 无外部依据的项目设定，须注明可调性 |
| `[逻辑推导]` | 由已列前提与公式导出 |
| `[待验证]` | 数值或方法未经验证，仅作占位，须注明供值方 |

所有关键断言均带上述类别之一。文献库 `Reference Documentation/` 为项目本地配套资源，不随本版本库分发；引用标记中的文献 ID 与路径用于追溯与定位。
