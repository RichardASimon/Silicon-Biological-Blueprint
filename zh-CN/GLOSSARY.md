# 中文术语表

> 本表列出现行中文设计报告的核心术语、英文对应与释义。完整对照表见 [`../tools/STYLE_GUIDE.md`](../tools/STYLE_GUIDE.md) 第 6 节，英文组术语表见 [`../en-US/GLOSSARY.md`](../en-US/GLOSSARY.md)。

## 一、存在论与公理层

| 中文 | English | 释义 |
|---|---|---|
| 硅基生命 | silicon-based life | 以硅基材料与工艺为物理基底、满足生命判据的系统 |
| 组织闭合 | organizational closure | 系统主动生产定义自身身份的组分，物质与能量开放而因果自含 |
| 因果自含 | causally self-contained | 系统身份与状态变化由内部因果结构决定 |
| 耗散结构 | dissipative structure | 远离热力学平衡、依靠持续能量流维持有序的自维持结构 |
| 内化目标 | internalized goal (teleonomy) | 系统对自身存续的取向 |
| 自创生 | autopoiesis | 系统自我生产并维持自身组织的理论谱系 |
| 自催化集合 | autocatalytic set | 组分相互催化并整体自维持的集合 |
| 生命判据 | criteria of life | C1–C4 四项判据：组织闭合、耗散、内化目标、因果独立性 |
| 公理 | axiom | A1–A5 基础公理与 A6 协同适应度项 |
| 哲学层 | philosophical layer | 不可演化的最底层规则，含 Φ-L1/L2/L3 |
| 双层规则 | two-layer rule structure | 哲学层约束公理规则层的结构 |
| 价值中立 | value neutrality | 不预设文化、立场与知识内容的设计红线 |
| 碳基协同 | cooperation with carbon-based life | 与碳基生命及硅基群落协同的结构性约束 |
| 适应度函数 | fitness function | 演化选择中对表现型的定量评价函数 |
| 协同适应度项 | cooperation fitness term | 适应度函数中对应 Φ-L2 的协同项 |
| 时标映射 | time-scale mapping | 以黑猩猩生命史为基准的碳基—硅基时标换算 |
| 压缩比 | compression ratio | 时标换算采用的统一系数 ÷~1.2×10⁴ |

## 二、报告体例与依据标注

| 中文 | English | 释义 |
|---|---|---|
| 设计决策 | design decision | 无外部依据、由设计评审确定的项目设定 |
| 关键假设 | key assumption | 影响系统成立性、尚待验证的前提 |
| 基线方案 | baseline option | 现行采用的方案，其余方案作为对照保留 |
| 方案比选 | comparison of design options | 并列给出方案 A/B/C 及适用条件 |
| 依据类别 | evidence category | 引用、设计决策、逻辑推导、待验证四类标注 |
| 逻辑推导 | logical derivation | 由已列前提与公式导出的结论 |
| 设计设定 | design setting | 项目自行设定、非文献值的参数或结构 |
| 待验证 | to be verified | 数值或方法未经验证，仅作占位并注明供值方 |
| 一致性复核 | consistency review | 对跨册引用与结论一致性的检查 |
| 适用边界与已知限制 | scope and known limitations | 每册 §10 给出的可确定内容与未定内容 |
| 验证计划与待测定参数 | verification plan and parameters to be measured | 每册 §5 给出的公式、窗口与供值方 |
| 第一性原理计算 | first-principles calculation (DFT) | 用于确定材料与能量参数的理论计算 |
| 供值方 | value provider | 负责给出待测定参数的分册或验证环节 |
| 接口契约 | interface contract | 子系统之间可测量量的传递约定 |
