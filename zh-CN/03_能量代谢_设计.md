## 0. 设计方案比选

> 设计问题：三类方案分别给出"获取/转化/分配 + 依据 + 可行性"。
> - **方案 A(概念方案)**:热电 TEG 主能源 + 类 ATP 电化学梯度能量币 + A2 序动态分配(当前 §2/§3)
> - **方案 B(基于项目文献库)**:文献库中最成熟的能量获取范式(热电/光催化/人工细胞代谢实测)
> - **方案 C(基于公开研究实践)**:外部调研(软体/可穿戴能量获取 + 能量存储 + 动态分配)给的可借鉴做法
>，可组合(§0.4)。

### 0.4 方案组合与基线配置

| 策略 | 内容 | 适合 |

### 0.5 能量代谢结构详解（文字说明）

> **本节为 §3 图 3-1 的文字说明**:不依赖图示，逐层说明"硅基个体一条能量流到底是什么、在哪获取/转化/存储/分配、动态回路怎么穿越它"。基于**方案 B(A+C 混合：热电获取 + 超级电容储能)**。

**轴 1:物理承载的 4 段(从获取到分配,"能量从哪来、到哪去")**

| 段 | 是什么 | 干什么 |
| ---- | -------- | -------- |
| **段1 获取(HARVEST)** | 3 源：热电 TEG(常态)/ 光催化制氢(峰值)/ 群落协同交换(备用) | 把环境里的能取进来(热电取温差、光催化取光能、协同从群落借) |
| **段2 转化(CONVERT)** | 热电产电 → 驱动离子泵建离子浓度梯度(类化学渗透) | 把"取来的电"转成可分配的中间形态(能量币) |
| **段3 存储(STORE)** | 超级电容 / µ-battery(方案 C)解耦"取"与"分" | 让能量币可缓冲——热电断续产电时，储能单元底层约束，分配端不掉电 |
| **段4 分配(ALLOCATE)** | 按 A2 序串行降级门控:生存>复制>学习>试跑>协同 | 把能量币按优先级投给各子系统;缺口时从下往上砍 |

**依据与说明（按上表行序）**

1. **段1 获取(HARVEST)** — 热电 [引用:`03/2026_Hybrid_TEG_PMMA_Ink_PoD40nW_cm2`(40 nW/cm²)、`03/Moradi-2025_Wearable_Thermoplasmonic_TE_0.15mW_cm2`(0.15 mW/cm²)];"三源优先级" [设计决策]
2. **段2 转化(CONVERT)** — 类化学渗透 [引用:`03/Chemiosmotic_Nutrient_Transport_Synthetic_Cells_Decarboxylation_2024`];"离子梯度=能量币" [设计决策]
3. **段3 存储(STORE)** — [引用:`03/E_HARVEST_STORE_MANAGE_..._2026-09-15` S1 Yin 2017 软水凝胶超级电容(与 03 POMs 同基质类型);S2 可调/S3 微系统/S4 峰值缓冲;补爬 µ-battery B1 Xu 2013 可拉伸软电池(OA)、B2 Moitzheim 2019 3D 薄膜锂微电池(突破 ≈250 µAh/cm² 平面足迹容量)]
4. **段4 分配(ALLOCATE)** — 优先级拓扑 [逻辑推导:A2 存续公理推论,00];各层"满足"阈值 [待验证]

**段与段的关系(图里自左而右的能量流链)**:
```
段1 获取(热电/光催化/协同) → 段2 转化(驱动离子泵建梯度)
     → 段3 存储(超级电容缓冲) → 段4 分配(A2 序投给 5 类子系统)
```
→ **"能量"不是独立的东西，它 = 段2 建出的离子梯度(能量币);要取到它靠段1,要稳住它靠段3,要花出去靠段4。** 这条链就是"硅基个体一条能量流长什么样"。

**轴 2:三条机制线(穿过 4 段,"怎么取/怎么转/怎么管")**

| 机制 | 穿过哪段 | 做什么 | 依据性质 |
| ------ | --------- | -------- | --------- |
| **取(HARVEST)** | 段1 → 段2 | 热电产电驱动离子泵；光催化峰值补；协同在缺能时从群落借 | 热电驱动 [引用:`03/Moradi-2025...`]、协同交换 [引用：原则 20 / 10 §3.5] |
| **分(DISTRIBUTE)** | 段4 | 串行降级门控：生存(组织闭合)先满足，未满足时下层的试跑/协同自动断电;缺口从下往上砍 | [逻辑推导:A2 序 + 00 存续公理];门控"断电"语义 [设计决策] |
| **管(ASSESS)** | 穿越段1-段4 的动态感知-评估回路(§3.4) | 个体实时感知当前收支(热电产电 vs 各子系统耗能),动态算盈余/缺口，反馈调分配；缺口持续→触发固定（不可演化）的求能本能 I0 | [引用：原则 20 能量动态评估 + 原则 15 时标基线];"感知-评估"回路本身 [设计决策] |

**取/管的"不作硬性设定"关系**(为什么这套设计能"既稳又能动态"):
- **段4 的优先级拓扑 = 固定（不可演化）**(A2 序：生存>复制>学习>试跑>协同，不可演化掉);
- **当前"花多少/缺口多少" = 动态**(§3.4 回路实时算，不作硬性设定数值);
- **求能本能 I0 的"驱动" = 固定（不可演化）,只让"找多少"动态**(原则 20);"固定（不可演化）拓扑 + 动态数值"的分法，正是**原则 20"能量动态评估不作硬性设定 + 求能本能必须存在"两条的对应落点** [逻辑推导：原则 20 两句话分别落到拓扑/数值]。

#### 要点归纳
> **硅基个体的一条能量流 = 段1 从热电/光催化/群落取能 → 段2 转成离子浓度梯度(能量币)→ 段3 用超级电容缓冲 → 段4 按 A2 序(生存>复制>学习>试跑>协同)投给各子系统，缺口时从下往上砍。感知-评估回路实时算盈余/缺口，缺口持续就触发固定（不可演化）的求能本能 I0。拓扑固定（不可演化）、数值动态，这就是"能量不作硬性设定"的具体形式。**

## 1. 设计目标
让硅基个体**获取能量 → 转化为"能量币"→ 分配给各子系统**(复制/神经/世界模型/协同),维持 A1 组织闭合(不瓦解)。
**关键约束(原则 20)**:
- 能量**不作硬性设定**——初始量级按"一个月"(黑猩猩基准，原则 15),但**个体自行感知 + 动态评估**当前收支
- **求能本能必须存在**(I0 组硬成员):"必须找能量"这个驱动固定（不可演化）,只让"找多少"动态

### 3.1 能量天花板约束(关键，基于实测)

**热电是当前硅基的能量瓶颈**——实测功率密度区间(**三个数值均为文献报告值，；待验证 · 不同温度/器件，不可直接比**):
```
0.03 µW/cm² 级(纳米阵列,10 K)[**固态·SiN悬空纳米 TEG,非凝胶对照**]    → `03/2018_Network_Thermoelectric_Nanogenerators_arXiv1811.08729`(低温**固态**实测;软基质内功率[待实验 E1]未知,**不得作凝胶上限**)
40 nW/cm²(TEG + PMMA 墨水)[固态]        → `03/2026_Hybrid_TEG_PMMA_Ink_40nW_cm2_arXiv2607.02793.pdf`(实测固态值,**仅对照,非凝胶上限**)
0.15 mW/cm²(热等离子,ΔT=13 K 温差)      → `03/Moradi-2025_Wearable_Thermo_plasma_0.15mW_cm2_arXiv2512.08103.pdf`(实测)
366 mW/cm³(体积密度,NiTi 热弹性)       → `03/2026_Thermoelastic_Harvesting_NiTi_366mW_cm3_arXiv2608.12092.pdf`(待验证 · 体积密度,非面密度,不可与上面直接比)
```
**含义**:
- 热电功率密度在**面密度 ~nW–mW/cm² 量级**(上述实测，注意各自温度不同)
- 硅基个体**能耗量级低**(mW 级，由上述热电功率反推的**量级判断**,**非实测**;碳基人脑 ~20 W 是常识对比，仅作量级参照,`无本项目出处`)
- **能量预算紧** → 个体不能"奢侈"地同时满负荷跑所有子系统
- **求能本能(I0)的优先级最高**:能量紧时，生存 > 复制 > 学习 > 世界模型试跑(按 A2 存续的优先级分配)
- **待实验验证**:热电在**硅基凝胶**(POMs)里的实际功率密度(现值是固态器件，凝胶里会掉)

### 3.3 能量币形态(类 ATP)
**参照碳基 ATP/还原力(NADH),硅基用"电化学势差"作能量币**:
- **形态**:凝胶基质的**离子浓度梯度**(类化学渗透,`Chemiosmotic_Nutrient_Transport_2024`)+ 电荷势差
- **转化**:热电产电 → 驱动离子泵建立梯度(类 ATP 合成)
- **使用**:梯度驱动复制(方案 B 的能量输入)/ 神经脉冲 / 世界模型试跑 / 协同通信
- **关键**:能量币是"**中间存储 + 分配**",不是"获取"——热电是获取，能量币是转化后的可分配形式

**E2 能量币形态细化(可推部分，原则 24)**:
- **主形态 = 离子浓度梯度**(类化学渗透,`03/Chemiosmotic_Nutrient_Transport_2024`):凝胶基质内的离子电化学势差 Δμ = RT·ln([ion]_in/[ion]_out)+ zF·ΔV。
- **可推依据**:凝胶宿主(§02 POMs)天然含水，离子可在凝胶孔道迁移 → **离子梯度**是凝胶环境里最自然的"能量币",比"固固界面电荷"更易在软基质里分配。
- **具体离子/浓度/势差值 = 待设计 + DFT**(哪种离子、多大浓度梯度、多大 Δμ,需对本凝胶体系实测；碳基 ATP 的 ΔG ~50 kJ/mol 只能作**量级参照**,`设计设定`,不迁移至硅基载体)。

**E4 分配拓扑细化(可推部分)**:
- **优先级拓扑(固定（不可演化）,A2 序)**:`生存(维持组织闭合)> 复制(方案 B 供能)> 学习(05 可塑性)> 试跑(06 世界模型模拟)> 协同通信`。
- **可推**:分配是**串行降级门控**——上层(生存)能量未满足时,**下层(试跑/协同)自动断电**。这是 A2 存续公理的直接推论(00),**拓扑结构可定**。
- **各层"满足"的阈值 = 待设计 + 实测**(多少能量算"生存满足"、多少"够试跑",数值无实测，原则 24 不臆断)。
- **落实**:§3.4 动态回路算出的"盈余/缺口"驱动这套拓扑——缺口时按拓扑**从下往上砍**(先砍协同，再砍试跑，再砍学习，保住复制 + 生存)。

### 3.4 动态感知-评估回路(原则 20,不作硬性设定)
```
感知:个体自带"能量传感器"(感知当前收支:热电产电 vs 各子系统耗能)
评估:动态算"能量盈余/缺口" → 调整分配优先级(生存 > 复制 > 学习 > 试跑)
反馈:缺口持续 → 触发求能本能(I0,固定（不可演化）驱动) → 趋向能源/协同
```
- **初始量级**:按"一个月"(黑猩猩基准，原则 15)设能量预算基线
- **不作硬性设定**:硬件堆叠/协同/演化都会改变实际耗能，所以"当前耗能"由个体**实时感知 + 评估**,不是固定值
- **设计含义**:03 给的是"**预算基线 + 动态回路**",不是"固定能量值"
- **P0 可证伪量化缺口估算(2026-09-16 T5 确定后补，量级表非精确设计值)**:单个体闭合 5 回路所需功率 vs 热电实测，缺口量级——

### 3.5 协同的能量收支(原则 20,群落协同)
- **协同 = 通信/交换 = 耗能**(信息传输付能)
- **收益**:资源交换 / 任务分工 / 信息共享(§10 A6 协同适应度项)
- **成本**:通信功耗 + 交换能量
- **净收益 = 协同收益 - 协同成本**（协同收益须大于协同成本）
- **落实在 §10 A6**:`w_synergy · [协同收益 - 协同成本]`,成本项含通信功耗
