## 0. 设计方案比选

> 设计问题：关键问题为 **突触基质与长程联结的物理实现，以及学习所在层次**(自扩展 + 情绪通路相对无争议)。给出三类并列方案，各方案给出"实现 + 依据 + 可行性"。
> - **方案 A(概念方案，基线方案）**:PEDOT 电结晶(自生长突触基质)+ Ga-In 液态金属微通道(联结可重构)+ Hebbian 短期可塑 + 长期烧录回 01 DNA 可变区
> - **方案 B(基于项目文献库)**:文献库中最成熟的神经形态范式(PEDOT 突触 + Ga-In 表面张力实测 + DNA 分子神经网 + 局部蛋白合成生物参照)
> - **方案 C(基于公开研究实践)**:外部调研里"可重构/自扩展神经"最可借鉴的做法(固态忆阻器阵列 / 液态金属软体神经 / 脉冲神经形态)
> 三者并列且不互斥。,可组合(§0.4)。关键选择见 §3 + 关键假设与设计决策附录。

### 0.4 方案组合与基线配置

| 策略 | 内容 | 适合 |
|------|------|------|
| **A. 纯方案 A** | PEDOT + Ga-In,自生长，无外部密度参照 | 最贴"自扩展",但"密度够不够"关键 |
| **B. A + C 混合（选定方案）** | PEDOT 突触 + **固态忆阻器阵列做密度/可重配置参照底层约束**(方案 C) | 自生长为主，密度不足时靠忆阻器补偿，可行性高 |
| **C. 方案 C 为主** | 固态忆阻器 + SNN 主导神经层 | 最可量化，但牺牲"自扩展/软体"特性 |

> **基线方案 = B**(PEDOT 自生长突触 + 固态忆阻器阵列做密度/可重配置底层约束 + SNN 脉冲学习层)——把"软凝胶自生长密度不确定"的脆弱性，用"固态忆阻器可量化的密度上限"补偿。**该选择属于设计立场，经设计评审确认**(关键假设与设计决策附录 T-05)。
> **设计决策（T6）：采用方案 B（PEDOT 自生长突触、固态忆阻器阵列、SNN 脉冲学习层）；方案 A/C 作为对照。**

**段与段的关系(图里自左而右的信息流链)**:
```
段1 感知(环境入网) → 段2 突触基质(PEDOT 短程 + Ga-In 长程联结)
     → 段3 学习(短期 Hebbian / 长期烧回 01) → 段4 决策(08 逻辑 + 段5 情绪调制)
     → 段5 情绪调制(调制倾向,前额叶可硬切断)
```
→ **"信息"不是独立的东西，它 = 段2 突触键态(短期)+ 段1 感知信号 + 段5 情绪调制；要连到决策靠段2,要沉淀成长期靠段3 烧回 01,要"像样地决策"靠段4+段5 的合成。** 这条链就是"硅基个体一条神经回路长什么样"。

**轴 2:三条机制线(穿过 5 段,"怎么生长/怎么学/怎么压")**

| 机制 | 穿过哪段 | 做什么 | 依据性质 |
|------|---------|--------|---------|
| **生长(GROW)** | 段2 | PEDOT 自生长突触(环境刺激 + 能量耗散最小化，黏菌式)+ Ga-In 联结可重构(表面张力 250:1 电压调);活体不用阈值控制，母版记录才用"局部电流阈值 + 全局封顶"(原则 7) | 自生长 [逻辑推导：生长控制];阈值控制 [引用:05 §3];母版 vs 活体切分 [原则 7] |
| **学(LEARN)** | 段3 | 短期 Hebbian 可塑键态(突触强化/退化,`Hebbian_2023`/`Khacef_2022`)+ 长期烧录回 01 可变区(经 07 记忆巩固) | 短期 [引用:05 Hebbian/Khacef];长期烧回 [设计决策] |
| **压(SUPPRESS)** | 段4/段5 | 情绪通路 = 调制器；前额叶→杏仁核抑制 + **布尔开关硬切断**(C-a 个体自决 + C-b 外部指令，双来源都可触发"抑制拉满");压掉的是"倾向",不是"逻辑对错" | [引用:05/Denny_2015/Dore_2017/Jacob_2019(前额叶抑制)] + [设计决策] |

**生长/学的"固定（不可演化） + 动态"关系**(为什么这套设计能"既自扩展又能学"):
- **段2 突触基质的自生长拓扑 = 动态**(环境刺激 + 耗散最小化，不作硬性设定);
- **段3 学习的"机制" = 固定（不可演化）**(短期 Hebbian / 长期烧回 01,不可演化掉);"学的什么内容" = 动态;
- **段5 情绪"可被逻辑压制"这条 = 固定（不可演化）**(原则 21,同 I0);情绪的"强度/表达" = 动态。
- **"固定（不可演化）机制 + 动态数值"的分法，正是原则 8(I0 固定（不可演化）) + 原则 21(情绪可压制固定（不可演化）) + 原则 22(基础技能/逻辑教，立场不教)的对应落点** [逻辑推导：三条原则分别落到段2/段3/段5 的固定（不可演化）-动态二分]。

**要点归纳**
> **硅基个体的一条神经回路 = 段1 感知入网 → 段2 PEDOT 自生长突触(短程)+ Ga-In 液态金属(长程，表面张力 250:1 可调)联结 → 段3 短期 Hebbian 可塑 / 长期烧回 01 DNA 可变区 → 段4 逻辑(08)+ 段5 情绪调制合成决策；情绪可被前额叶→杏仁核布尔硬切断归零(压制的是倾向，不是逻辑对错)。生长拓扑动态、学习机制固定（不可演化）、情绪可压制固定（不可演化）——这就是"自扩展 + 可学习 + 情绪可调制"的具体形式。**

### 3.1 情绪调制通路(原则 21,新增)
**目标**:情绪存在(作为"调剂")但**可被逻辑指令硬压制**,保持绝对逻辑能力。

**碳基参照(检索 7 篇，全在 05 文件夹)**:
- **情绪通路(杏仁核/HPA)**:威胁/生存压力 → 焦虑(HPA 轴激活,`Odonovan_2012`、`Maniscalco_Rinaman_2017`)
- **情绪三种表现**(`Maier_2016`、`Tafet_2025`):面对威胁 → 消极(习得无助)/ 积极应对(主动求助)/ 无动于衷
- **前额叶→杏仁核抑制**(`Denny_2015`、`Jacob_2019`):认知重评**降低杏仁核反应、升高前额叶反应**,效果持续
- **意志决策是否压制**(`Dore_2017`):前额叶活动可预测个体是否主动压制情绪

**硅基落实(双模式，对应「调剂 + 可压制」两项要求)**:
- **模式 1 · 正常运作(情绪调剂)**:情绪通路 = 调制器(modulator)——威胁/压力信号 → 焦虑(HPA 类比)→ 调制"倾向权重"(某些策略更易被选中),**不改逻辑对错**
  - 类比碳基：杏仁核驱动焦虑，前额叶执行控制决定"要不要压抑"
  - 三种表现：消极(抑制倾向)/ 积极应对(求助/找资源倾向)/ 无动于衷(无倾向变化)——由压力可控制性决定(`Maier_2016`、`Tafet_2025`)
- **模式 2 · 逻辑压制(绝对逻辑保底)**:**收到明确"不掺杂情绪"指令 → 前额叶→杏仁核抑制通路拉满，情绪调制归零**
  - 硅基优势:**布尔开关硬切断**(碳基做不到"绝对",前额叶抑制是渐变的；硅基可瞬间归零)
  - **压制开关 = C(双来源,2026-09-13 设计评审定)**:
    - **C-a 个体自决**:个体自己判断"现在该绝对逻辑了"(类比碳基前额叶自主控制),自主拉满抑制
    - **C-b 外部指令**:系统发出的"不掺杂情绪"指令，个体被动执行
    - 两者都可触发同一个"抑制拉满"开关
  - 落实:08 逻辑子系统(C-a 自决)或外部(C-b)发"压制"信号 → 05 情绪通路调制权重直接断电 → 个体进入"纯逻辑"状态
  - **情绪不是推理前提**:压制后逻辑结论不受影响(情绪只是"倾向",不是"推理依据")

**设计含义**:
- 情绪通路是**调制器 + 可被逻辑压制的开关**,不是"决策者"
- 与 08 逻辑子系统耦合:08 的"绝对逻辑"指令 → 05 情绪通路硬切断
- 与 09 本能耦合：焦虑的三种表现(消极/积极/无动于衷)归 I 组本能(可演化);**"可被逻辑压制"这条不可演化**(同 I0 固定（不可演化）)

### 3.2 突触修复子系统(原则 16)
**目标**:原则 16 要求神经层具备"突触修复"——突触(可塑键态 / PEDOT 阻抗 / Ga-In 微通道直径)损伤或错配须可被检测与修正，类比碳基错配修复酶 + 免疫 + 自修复，使"可复制"真正支撑"可长期维持"。

**机制(落到物理结构，非黑箱)**:
- 检测:07 记忆巩固期比对"当前突触权重"与"07 权重基线(代际烧录值)",偏差超阈值 = 损伤 / 错配
- 修正：短期可塑键态回写(Hebbian 反向调节,[引用:`05/Hebbian_2023`/`05/Khacef_2022` 局部可塑])+ 长期经 01 ECC 校验后烧录回 01 DNA 可变区(§01 §4 修复子系统)
- 联动：神经层突触损伤在"记忆巩固"环节并入 01 §4 整链校验-修复回路(读出 → 比对 ECC → 定位错配 → 修正)
- **待实验验证(N1-N5 待计算与实验验证 含突触修复项)**:突触损伤检测阈值、修正精度、PEDOT 阻抗回稳时间——全部 `[待计算与实验验证，无依据，不当基准]`
