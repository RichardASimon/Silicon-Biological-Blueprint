# Glossary

> Core terms used in the English design reports, with Chinese equivalents. The complete terminology table is in [`../tools/STYLE_GUIDE.md`](../tools/STYLE_GUIDE.md), Section 6; the Chinese glossary is in [`../zh-CN/GLOSSARY.md`](../zh-CN/GLOSSARY.md).

## 1. Ontology and Axiomatic Layer

| English | 中文 | Definition |
|---|---|---|
| silicon-based life | 硅基生命 | A system built on silicon materials and processes that satisfies the criteria of life |
| organizational closure | 组织闭合 | The system actively produces the components that define its identity; materially and energetically open, causally self-contained |
| causally self-contained | 因果自含 | Identity and state changes are determined by the internal causal structure |
| dissipative structure | 耗散结构 | A self-maintaining ordered structure sustained by continuous energy flow far from thermodynamic equilibrium |
| internalized goal (teleonomy) | 内化目标 | The system's orientation towards its own persistence |
| autopoiesis | 自创生 | The theoretical lineage of systems that produce and maintain their own organisation |
| autocatalytic set | 自催化集合 | A set of components that catalyse one another and maintain the whole |
| criteria of life | 生命判据 | Four criteria C1–C4: organisational closure, dissipation, internalized goal, causal independence |
| axiom | 公理 | Foundational axioms A1–A5 plus the cooperation fitness term A6 |
| philosophical layer | 哲学层 | The non-evolvable lowest rule layer, comprising Φ-L1/L2/L3 |
| two-layer rule structure | 双层规则 | A structure in which the philosophical layer constrains the axiomatic rule layer |
| value neutrality | 价值中立 | A design red line: no preset culture, stance or knowledge content |
| cooperation with carbon-based life | 碳基协同 | A structural constraint requiring cooperation with carbon-based life and silicon-based communities |
| fitness function | 适应度函数 | The quantitative evaluation of phenotypes in evolutionary selection |
| cooperation fitness term | 协同适应度项 | The component of the fitness function corresponding to Φ-L2 |
| time-scale mapping | 时标映射 | Conversion between carbon-based and silicon-based time scales using a chimpanzee life-history baseline |
| compression ratio | 压缩比 | The uniform coefficient ÷~1.2×10⁴ used in time-scale conversion |

## 2. Report Conventions and Evidence Tags

| English | 中文 | Definition |
|---|---|---|
| design decision | 设计决策 | A project setting without external evidence, confirmed by design review |
| key assumption | 关键假设 | A premise affecting system validity that remains to be verified |
| baseline option | 基线方案 | The option currently adopted; other options are retained as alternatives |
| comparison of design options | 方案比选 | Parallel presentation of options A/B/C with their conditions of applicability |
| evidence category | 依据类别 | One of four tags: reference, design decision, logical derivation, to be verified |
| logical derivation | 逻辑推导 | A conclusion derived from listed premises and formulae |
| design setting | 设计设定 | A parameter or structure set by the project rather than taken from literature |
| to be verified | 待验证 | An unvalidated value or method; placeholder only, with a named value provider |
| consistency review | 一致性复核 | A check of cross-volume references and conclusion consistency |
| scope and known limitations | 适用边界与已知限制 | Section 10 of each volume: what is determined and what remains open |
| verification plan and parameters to be measured | 验证计划与待测定参数 | Section 5 of each volume: formulae, windows and value providers |
| first-principles calculation (DFT) | 第一性原理计算 | Theoretical computation used to determine material and energy parameters |
| value provider | 供值方 | The volume or verification step responsible for supplying a parameter |
| interface contract | 接口契约 | An agreement on measurable quantities exchanged between subsystems |

## 3. Subsystems and Technical Terms

| English | 中文 | Definition |
|---|---|---|
| DNA information layer | DNA 信息层 | The information carrier recording construction rules, instincts and the axiom checksum |
| axiom checksum | 公理校验子 | An encoding used to verify the fidelity of the fixed axiom region |
| replication fidelity | 复制保真度 | The degree to which information is preserved across generations, denoted ε |
| side-group bonding state | 侧基键态 | A physical scheme encoding information bits in side-group bond states |
| multi-defect cluster | 多缺陷簇 | A defect cluster used to stabilise bonding states |
| atomic layer deposition (ALD) | 原子层沉积 | A process for carrier encapsulation and layer-by-layer construction |
| energy metabolism | 能量代谢 | Subsystem S3 for energy acquisition, conversion and allocation |
| energy currency | 能量币 | A unified internal carrier for energy accounting |
| dynamic power management | 动态功率管理 | A mechanism allocating power according to load and storage state |
| boundary and individuality | 边界与个体性 | Subsystem S4: criteria and boundary defining a single individual |
| artificial seeding | 人工播种 | Construction of the first candidate individual by an external operator |
| emergence-based viability assessment | 涌现判活 | Assessment of whether a candidate individual satisfies C1–C4 |
| self-maintenance | 自维持 | The ability of an individual to maintain organisational closure in an open environment |
| neural network | 神经网络 | Subsystem S2 for perception, decision-making, learning and affective modulation |
| affective modulation | 情绪调制 | An affect pathway that can be suppressed by logic |
| synapse | 突触 | The physical substrate of memory and learning |
| memristor | 忆阻器 | A solid-state device used for density and reconfigurability |
| world model | 世界模型 | Subsystem S5: internal predictive model and action-consequence simulation |
| recurrent state-space model (RSSM) | 循环状态空间模型 | The latent-variable prediction structure of the world model |
| latent variable | 潜变量 | The internal state representation of the world model |
| action operator | 作用算子 | A three-step mapping from individual actions to changes in the world model state |
| memory consolidation | 记忆巩固 | The process converting experience into a stable structure |
| epigenetic inheritance | 表观遗传 | Cross-generational phenotypic transfer without sequence changes |
| intergenerational transfer | 跨代传递 | Transfer of information or experience between generations |
| minimal logic set | 最小逻辑集 | The minimal set of AND/OR/NOT and basic conditional operations |
| I0 prerequisite set | I0 判定前提集 | The fixed instinctive prerequisites required for the criterion of life |
| hard core / soft extension | 硬核心 / 软扩展 | Instincts derived from axioms / instincts chosen by design |
| evolutionary selection | 演化选择 | Subsystem S6: mutation, fitness adjudication and intergenerational transfer |
| selection pressure | 选择压力 | The mechanism determining phenotype retention and elimination |
| quality-diversity (QD) | 质量多样性 | An evolutionary method organising search by measurable descriptors |
| retention/elimination interface | 保留/淘汰接口 | An interface for manual selection subject to Φ-L2/A6 validation |
| system integration | 系统整合 | Final assembly, loop closure and the minimum buildable set |
| closure of the five loops | 五回路闭合 | The cycle of perception, decision, action, energy and replication |
| minimum buildable set | 最小可构建集 | The minimal set of subsystems required at the current stage |
