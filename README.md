### Reading Order

1. Volume 00 — axioms, two-layer rule structure and time-scale mapping.
2. Volumes 01–10 — subsystem designs in dependency order.
3. Volume 11 — final assembly, closure of the five loops and the minimum buildable set.
4. Section 5 (verification plan) and Section 10 (scope and known limitations) of each volume.

### Conventions

- Versions are recorded per volume and are identical across the two languages.
- Evidence categories: `[Ref:…]` (literature or data), `[Design decision]` (project setting without external evidence), `[Logical derivation]`, `[To be verified]`. The Chinese edition uses `[引用:…]`、`[设计决策]`、`[逻辑推导]`、`[待验证]`.
- The `Reference Documentation/` library is a local companion resource and is not distributed with this repository; literature IDs and paths in reference tags serve traceability.
- Parameters without measured values are listed as verification items and are not used as design baselines.

## 中文

设计报告按语言分组存放：`en-US/` 为英文组，`zh-CN/` 为中文组。两组各 12 册，章节编号、公式、引用标记与术语逐册对应。上表即为分册对照索引。

### 阅读顺序

1. `00` 哲学层：公理、双层规则与时标映射。
2. `01`–`10`：按依赖顺序阅读各子系统设计。
3. `11` 系统整合：总装、五回路闭合与最小可构建集。
4. 每册 `§5` 验证计划与 `§10` 适用边界与已知限制。

### 文档约定

- 版本按册标注，两种语言版本号一致。
- 依据类别：`[引用:…]` 文献或数据、`[设计决策]` 无外部依据的项目设定、`[逻辑推导]` 由已列前提导出、`[待验证]` 仅作占位并注明供值方；英文版对应 `[Ref:…]`、`[Design decision]`、`[Logical derivation]`、`[To be verified]`。
- 文献库 `Reference Documentation/` 为项目本地配套资源，不随本版本库分发；引用标记中的文献 ID 与路径用于追溯与定位。
- 未给出实测值的参数一律列为待验证项，不作为设计基准值。
